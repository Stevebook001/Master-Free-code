### 🔥 What is Master Free Code?

Master Free Code is a free, community-driven coding school. Just like freeCodeCamp.org, we believe code education should be free and accessible.

We teach through:
- **Learn:** Interactive lessons (MERN, Python, AI, Game Dev)
- **Build:** 100+ hands-on projects
- **Share:** Portfolio + GitHub
- **Earn:** Freelancing & Job Prep

### 🗺️ Curriculum Roadmap (like freeCodeCamp)

#### 1. Responsive Web Design
- HTML5, CSS3, Tailwind, Flexbox, Grid
- Project: Build your Portfolio (like https://akode-nine.vercel.app)

#### 2. JavaScript & Frontend
- Vanilla JS, DOM, React.js, Next.js
- Project: Clone WhatsApp Web / Twitter

#### 3. Backend & Databases
- Node.js, Express, MongoDB, PostgreSQL, Supabase
- Project: REST API + Auth System

#### 4. Python & AI Engineering
- Python, Pandas, PyTorch, LLMs
- Project: Build your own mini AI like EVY AI (by CJ)

#### 5. Mobile & Game Dev
- Flutter, Unity, C#
- Project: 2D Mobile Game

#### 6. Freelancing & Career
- GitHub, Vercel, Upwork, Fiverr, Resume

> Each course = Lessons + 5 Projects + Certificate
