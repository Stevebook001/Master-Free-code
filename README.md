### 🔥 What is Master Free Code?

Master Free Code is a free, community-driven coding school. Just like, we believe code education should be free and accessible.

We teach through:
- **Learn:** Interactive lessons (MERN, Python, AI, Game Dev)
- **Build:** 100+ hands-on projects
- **Share:** Portfolio + GitHub
- **Earn:** Freelancing & Job Prep

### 🤝 How to Contribute (Make it grow fast)

We use the freeCodeCamp contribution model:

1.  Fork this repo
2.  Pick a lesson in `/curriculum` that is missing
3.  Create a new folder: `lesson-name` with `README.md` + `code/`
4.  Submit a Pull Request

**Easy first contributions:**
- Add your portfolio to `/community/members.json`
- Fix a typo
- Add a project tutorial
- Translate a lesson to Hausa / Yoruba / Igbo / Pidgin

See [CONTRIBUTING.md](CONTRIBUTING.md) for full rules.
